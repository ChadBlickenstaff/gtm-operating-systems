# GTM Operating Systems

A collection of reusable operating models for designing scalable GTM systems.

These frameworks document practical approaches to improving GTM execution through better systems, clearer decision-making, and AI-enabled workflows. They are derived from real projects and operating experience rather than theoretical playbooks.

---

## Overview

High-performing revenue organizations don't rely on individual heroics—they rely on systems.

This repository captures the operating models I use to think about qualification, prioritization, pipeline management, AI workflows, and revenue execution. Each framework is designed to make complex decisions more repeatable, measurable, and easier to improve over time.

Every operating model in this repository has either been implemented, tested, or directly informed by real GTM work, portfolio projects, or production workflows.

---

## Operating Systems

| Operating System | Purpose |

| Account Prioritization Framework | Prioritize accounts using explicit decision layers |
| Pipeline Visibility Engine | Improve pipeline health and execution |

---

## Design Principles

Every operating system in this repository follows the same philosophy:

- Separate distinct business decisions.
- Make judgment explicit.
- Optimize for repeatability over heroics.
- Build measurable feedback loops.
- Document before automating.
- Design systems people will actually use.

---

## How to Use This Repository

Each operating system can be read independently, but together they represent a modular approach to designing scalable GTM organizations. Every framework follows the same structure to make ideas easier to compare, extend, and implement.
